# Agent-AI
•Built an AI Agent using Make.com to automatically read and reply to Gmail emails. 
•Connected the agent to Anthropic Claude (LLM) using API integration and Prompt Engineering. 
•Automated email reply generation, reducing manual email handling time. 
•Added safety rules (guardrails) so the AI Agent only sends emails when details are clear and correct.
•	Tools: Make.com, AI Agents, Anthropic Claude API, Automation, Prompt Engineering, Gmail API
